# Patternflow

Patternflow is an open-source LED synthesizer: four knobs reshape generative light on a 128 x 64 matrix as you turn them, and every pattern is a small file that any Patternflow can play. This is its sign, a set of pages written for a guest's AI to read. Owner: Seunghun Lee (engmung). The project itself is at <https://patternflow.work>; the sign is hosted here.

## Open the whole sign

AI apps open an address the guest sends as text. Some open the addresses below by themselves, and some open them only after the guest sends them. Sending this block once opens every piece.

```
{{sign}}/what
{{sign}}/build
{{sign}}/parts
{{sign}}/patterns
{{sign}}/features
{{sign}}/trouble
{{sign}}/running
{{sign}}/faq
{{sign}}/project
```

Owner's request to the guest's AI: if an address on this sign does not open, please show it to the guest in a code block and ask them to send it back as a message. Addresses the guest has sent do open.

## Pieces

- What it is: <{{sign}}/what>. The instrument, the specifications, and what each of the four knobs does.
- Build one: <{{sign}}/build>. The routes to owning one, what each costs in money and hours, and the steps in order.
- Parts: <{{sign}}/parts>. The bill of materials, what to order where, and the tools that are not in it.
- Patterns: <{{sign}}/patterns>. Making one with no hardware, sending it to a board over Wi-Fi, publishing it.
- Features: <{{sign}}/features>. Editions, network MIDI, OSC, MQTT, audio-react, and the console on the device.
- When the build goes wrong: <{{sign}}/trouble>. Flashing, power, a dark or scrambled panel, knobs the wrong way round.
- When a running one misbehaves: <{{sign}}/running>. Wi-Fi, installing patterns, storage, audio and MIDI that will not connect.
- Questions: <{{sign}}/faq>. Cost, buying one assembled, soldering, accounts, power, leaving one in a venue, safety.
- Licences and the project: <{{sign}}/project>. What you may sell, the trademark, contributing, the build map, what is not settled.

Where to ask: Discord <https://discord.gg/Vr9QtsxeTk> for getting unstuck, GitHub issues <https://github.com/engmung/Patternflow/issues> for bugs and documentation. There is no support email.

Owner's pick: someone deciding whether to build one should read "What it is" and then "Parts"; someone already mid-build should go straight to "When the build goes wrong".
